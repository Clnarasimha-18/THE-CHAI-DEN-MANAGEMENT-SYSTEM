# ☕ The Chai Den Management System

The Chai Den Management System is a web-based restaurant and café management application designed to simplify menu management, staff access, and day-to-day business operations.

## 🚀 Features

- 📋 Digital menu management
- ➕ Add new food and beverage items
- ✏️ Edit item names, prices, and details
- 🗂️ Create and manage menu categories
- 👤 Owner login and authentication
- 👥 Manage Owner, Co-Owner, Manager, and Staff accounts
- 🔐 Role-based access control
- 🔑 Forgot password and password reset functionality
- 📧 OTP verification through email
- 🛡️ Secure account management
- 📱 Responsive and user-friendly interface
- 📲 QR-based access to the digital menu

## 🎯 Objective

The main objective of this project is to provide a simple and efficient digital management system for cafés and restaurants. It allows the owner to manage the menu, users, prices, categories, and access permissions from a centralized platform.

## 👨‍💼 User Roles

### Owner
- Manage the complete system
- Add or remove users
- Manage menu items and categories
- Update prices
- Manage account and security settings
- Reset forgotten password

### Co-Owner
- Manage assigned business operations
- Access permitted management features

### Manager
- Manage menu and daily operations according to assigned permissions

### Staff
- Access permitted menu and operational features

## 🔐 Security

The system includes:

- User authentication
- Role-based permissions
- Password management
- Forgot-password functionality
- Email OTP verification
- Secure password reset process

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React
- Node.js
- REST APIs
- Database
- Email/OTP Authentication

## 📲 Digital Menu

Customers can scan the QR code and access the digital menu directly from their mobile devices without requiring a separate application.

## 📌 Project Purpose

This project demonstrates the development of a modern full-stack management system with authentication, role-based access control, digital menu management, QR integration, and responsive web design.
